🔢 Sorting Visualizer – Interactive Algorithm

Sorting Visualizer is a React-powered full-stack web application that transforms abstract sorting algorithms into colorful, real-time animations. Designed for students and curious minds, it combines an intuitive UI with secure backend functionality, allowing users not only to explore algorithms visually but also to personalize and save their learning experience.

✨ Highlights

🎞️ Live Animations
Visualize every comparison and swap step-by-step with smooth, real-time animations.

🔄 Algorithms Included
Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, and Quick Sort.

🧮 Adjustable Parameters
Dynamically control array size, animation speed, and visualization behavior to better understand time complexity.

🎨 Polished, Dynamic UI
Modern, responsive interface with smooth transitions, clear status indicators, and customizable color themes.

📱 Fully Responsive Design
Optimized for desktops, tablets, and mobile devices.

🔐 User Authentication & Personalization
Users can securely register and log in using JWT-based authentication with bcrypt-hashed passwords.

💾 Saved Configurations
Authenticated users can create, update, and delete their own visualization configurations (preferred algorithm, speed, UI settings), stored persistently in a database.

🛠 Full-Stack Implementation
Handled both frontend UI/UX development and backend responsibilities, including database design, authentication, REST API development, and frontend–backend integration.
